1\. Content Quality

The module must contain accurate, complete, and relevant information that supports the learning objectives. All explanations, definitions, examples, and technical details must be correct and easy to understand. The content should be written in the team's own words, avoiding unnecessary repetition and irrelevant information.

2\. Readability and Language

The text must be easy to read and understand. Use simple language, clear sentences, appropriate font sizes, readable fonts, and sufficient spacing. Grammar, spelling, and punctuation must be correct, and technical terms should be used consistently throughout the module.

3\. Structure and Organization

The module must be organized logically, starting with basic concepts before progressing to more advanced topics. Use clear headings, subheadings, numbered lists, and consistent formatting to help readers navigate the content. Learning objectives should be stated clearly, and important concepts should be summarized at the end of each major section.

4\. Reliable Sources and References

The information must be supported by trustworthy sources, such as academic textbooks, peer-reviewed research papers, university publications, and official documentation. Sources must be cited properly near the relevant information, and a complete reference list should be provided. All references must be checked to ensure they are credible, relevant, and accessible.

5\. Examples and Practical Applications

The module should include relevant examples and practical applications to help learners understand how theoretical concepts work in real situations. Worked examples should explain each step clearly rather than presenting only the final answer. For technical subjects, code examples, formulas, and outputs must be tested and verified.

6\. Visual Design and Layout

The module should have a clean, professional, and visually consistent design. Use relevant diagrams, charts, tables, and illustrations to make complex concepts easier to understand. Avoid overcrowding pages with too much text or too many images. Ensure sufficient color contrast, readable text, and consistent use of fonts, colors, and visual elements.

7\. Learning Activities and Exercises

The module should include exercises, practice questions, quizzes, or interactive activities that allow learners to apply their knowledge. Activities should match the learning objectives and progress from basic to more challenging tasks. Answer keys or explanations should be provided when appropriate to help learners evaluate their understanding.

8\. Learning Objectives and Effectiveness

The module must clearly explain what learners are expected to understand or achieve after completing each section. Every major topic should contribute to these objectives. The explanations and activities should support independent learning, allowing learners to study and understand the material without constantly requiring assistance from a teacher.

9\. Technical Accuracy and Functionality

All technical information, mathematical formulas, code snippets, and example outputs must be accurate and consistent with the explanations. Code should be readable, properly formatted, and tested when applicable. External links must work correctly, and Markdown formatting should display properly on the intended platform, such as GitHub.

10\. Consistency Across Learning Materials

The study guide, presentation slides, and video tutorials must communicate consistent information and use the same terminology, definitions, examples, and learning objectives. Each material should complement the others and provide a consistent learning experience without unnecessary repetition or contradictory explanations.

11\. Originality, Copyright, and AI Transparency

The module should demonstrate the team's own understanding of the subject. Borrowed ideas, text, images, and other materials must be properly attributed, and copyright requirements must be respected. Any AI assistance should be recorded according to the assignment instructions, and AI-generated information must be checked for accuracy before being included.

12\. Final Review and Quality Assurance

Before submission, the entire module must be reviewed for accuracy, readability, completeness, formatting, and consistency. Team members should proofread the content, verify the references, test technical examples, check links, and confirm that all assignment requirements have been fulfilled. The final module should be clear, reliable, well-organized, and ready for learners to use.
