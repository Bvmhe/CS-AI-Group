# Module Outline — Hardware, Networks & Behaviourist AI

## Intended Learning Outcomes
By the end of this module, learners should be able to:
1. Identify CPU, GPU, TPU, memory, and sensors and explain their functions in AI systems.
2. Explain how networks enable AI devices to communicate, exchange data, and access information.
3. Describe how behaviourist AI systems learn through interaction, feedback, and rewards.
4. Connect hardware, networks, and behaviourist AI to real applications (self-driving cars, smart devices, robots).
5. Build a foundation for more advanced AI concepts.

## Prerequisite Knowledge
- Basic computer architecture (CPU, memory)
- Programming fundamentals
- Basic computer network concepts
