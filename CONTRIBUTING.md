# Contributing Guidelines

## Branch Naming

Use this format: `<type>/<topic>`

Examples:
- `content/01-ai-hardware`
- `docs/readme`
- `review/01-hardware-check`
- `evidence/stage1-capture`

## Commit Messages

Write clear, meaningful messages:
- Good: `Add worked example for CPU vs GPU comparison`
- Bad: `update`, `final`, `fix`

## Pull Requests

1. Create a feature branch from `main`
2. Commit your changes with a meaningful message
3. Open a Pull Request
4. Request review from at least **one** other member
5. Merge only after approval
6. Merge by: CIO (林元甲) or CEO (纪小佩)

## File Paths

- Use **relative paths** for all images and assets
- Example: `![Diagram](../assets/images/01-cpu-gpu-tpu.png)`
- Never use absolute paths (`/Users/...` or `C:\...`)

## Individual Contributions

Each member must commit their own work using their own GitHub account.
If work is uploaded on behalf of another member, identify both the author and uploader in the commit message:
`Add review record (author: 温俊强, uploader: 林元甲)`
