# 🍳 Mama's Quiz Kitchen · Stage 2 Test Bank (game + paper)

Our Stage 2 Test Bank: 60 questions (25 True/False, 25 multiple choice, 10 open) in two versions, a game and a paper version. Both cover all five recipes of the Study Guide and include every answer.

| File | What it is |
|------|------------|
| `Mamas_Quiz_Kitchen.html` | **Game version.** Download it and open it in any browser (phone or computer, no internet needed). Pick one of 5 kitchen stations or play the Full Course Banquet. Instant feedback with Mama's tips, streaks, stars and medals, flip-card model answers with self-marking for open questions, and a "re-cook my mistakes" round. |
| `FengweiFriedRice_Stage2_TestBank_Paper.docx` | **Paper version** (editable Word, the file to hand in). Questions grouped by station on recipe cards, clickable tick boxes, "Mama's answer ▸" links to the answer key and "◂ Back" links, plus a scorecard for each station. |
| `FengweiFriedRice_Stage2_TestBank_Paper.pdf` | PDF copy of the paper version (the links work in the PDF too). |

GitHub shows `.html` files as code, so to play the game, download the file and open it, or use GitHub Pages if the repo owner turns it on.
