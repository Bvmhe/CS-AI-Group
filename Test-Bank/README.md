# Test Bank · Fengwei Fried Rice (Stage 2)

Separate, editable Test Bank for the study guide *Hot Wok, Smart Chips*.

- `FengweiFriedRice_Stage2_TestBank_V1.docx` – editable Word file (questions first, answer key after)
- `FengweiFriedRice_Stage2_TestBank_V1.pdf` – PDF copy

60 questions: 25 True/False, 25 multiple-choice (21 choose-one, 4 select-all), 10 open.
5 T/F + 5 MC + 2 open per recipe; every Kitchen Lab is used at least once, with all data in the question.

Regenerate with `python Study-Guide/tools/make_testbank.py`.
