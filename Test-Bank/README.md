# Fengwei Fried Rice · Stage 2 Test Bank

Separate Test Bank for the study guide *Hot Wok, Smart Chips*.

| File | What it is |
|------|------------|
| [Questions.md](Questions.md) | All 60 questions written out one by one (read them here on GitHub, no answers) |
| [FengweiFriedRice_Stage2_TestBank_AnswerKey.pdf](FengweiFriedRice_Stage2_TestBank_AnswerKey.pdf) | Answer key only: T/F corrections, MC reasoning, open-question key points and marks |
| `FengweiFriedRice_Stage2_TestBank_V1.docx` | Editable Word file: questions first, answer key after (the file to hand in) |
| `FengweiFriedRice_Stage2_TestBank_V1.pdf` | PDF copy of the Word file |

60 questions: 25 True/False, 25 multiple-choice (21 choose-one, 4 select-all), 10 open.
5 T/F + 5 MC + 2 open per recipe; every Kitchen Lab is used at least once, with all data in the question.

Regenerate with `python Study-Guide/tools/make_testbank.py`.
